# Otsingu privaatsuspiir

Keskkonnaportaali praktikaprojekt ei ole Keskkonnaportaali ametlik tootmiskeskkond. Otsing on mõeldud avalike keskkonnaallikate leidmise ja allikapõhise vastuse demonstratsiooniks. Otsingusse ei tohi sisestada tundlikke isikuandmeid.

Kasutajaliides hoiab otsingu- ja jätkuküsimuse vormid võimalikult kompaktsed. Tehnilise andmevoo ja teenusepakkuja tingimuste kirjeldus asub lehe jaluses jaotises „Otsingu ja AI-vastuse privaatsus”.

## Mis liigub kuhu

- Kui otsinguväljale on kirjutatud vähemalt kaks ja kõige rohkem 80 märki, saadab brauser 180 ms viite järel teksti sama päritolu serverile JSON POST-kehas ning server küsib selle tekstiga Keskkonnaportaalilt soovitusi. Soovitustel on eraldi kliendikvoot, kahe välispäringu töökoha piir, sama päringu koondamine ja katkestussignaal; vastuste vahemälu piiravad nii kirjete arv kui ka baitide kogumaht. See toimub enne nupu „Küsi” vajutamist; Lunale sel ajal päringut ei saadeta.
- Otsingu või jätkuküsimuse saatmisel liigub tekst sama päritolu serverile JSON POST-kehas. Tekst ei lähe URL-i, lehe pealkirja, cookie'sse, `localStorage`'isse ega `sessionStorage`'isse. Server saadab portaaliotsinguks vajalikud sõnad ametlikele otsinguteenustele. Terrapointi iframe ei saa üldotsingu päringut.
- Kui tõendikvaliteet on piisav, saab OpenCode Go Luna otsingu toorteksti, kuni kümne juba järjestatud avaliku allika päringupõhiselt valitud väljavõtted (kokku kuni 36 000 märki) ja väljundskeemi. Mitme allika korral juhib OpenAI Agents SDK manager relevantsusspetsialisti ja vajaduse korral tõendikriitikut; need on sama teenuse mudelikutsed ning neile ei anta algsest tõendipakist laiemaid andmeid. Jätkuküsimuse korral lisandub kuni 1 400 märki varasemate küsimuste konteksti. Kontekst aitab mõista jätkuküsimust, kuid seda ei käsitata faktitõendina.
- Manager ega spetsialistid ei saa kasutaja IP-aadressi, brauseri küpsiseid, PostgreSQL-i sisu, kogu otsingukorpust, Terrapointi andmeid, shelli ega veebitööriistu. Nende ainsad SDK tööriistad on kaks eelkirjeldatud piiratud spetsialisti; kumbki ei ava ise uusi allikaid.
- Praktikaportaali PostgreSQL-i otsingulogis on ainult eraldi vähemalt 32 juhusliku baidiga serverisaladuse võtmega HMAC-SHA-256 sõrmejälg, kestus ja kasutatud dokumentide ID-d. Püsiva andmebaasi korral ei käivitu server puuduva, ennustatava või andmebaasi mandaadiga kattuva võtmega. Sõrmejälge ei saa ilma selle sõltumatu serverisaladuseta võimalike päringute sõnastiku abil tagasi arvutada. Vastusevahemälu kasutab ranget `privacy-safe-v5` väljaskeemi: mudeli loodud vastuseproosat ei kirjutata ühisesse PostgreSQL-i cache'i ning sinna lubatakse ainult deterministliku serveritee kontrollitud mall ja ametlike allikate avalikud väljad. Päring ja sellest moodustatud pealkiri jäetakse salvestamata; ka täieliku päringu või mistahes vähemalt kolmetähelise sisulise päringutokeni otse, käändevormis või korduvalt URL-, HTML- või kaldkriipsuga põgenemise järel säilimine tühistab kogu cache-kirjutuse. E-posti aadressi, telefoni, isikukoodi, UUID-d, katastritunnust või pikka unikaalset täht-numbrilist tunnust sisaldavat päringut ei salvestata vastusevahemällu üldse. Kontroll teeb piiratud töömahuga semantilise väljade puu dekodeerimise fikspunktini; mittekonvergeeruv väärtus jätab cache-kirjutuse ära, kuid tehniline redigeeritud run-kirje säilib. Lugemisel moodustatakse päringupõhine pealkiri uuesti ainult jooksva päringu protsessimälus. Varasemad võtme- ja vahemäluskeemid kustutatakse migratsiooniga; vanu varukoopiaid tuleb hoida piiratud ligipääsuga ja eemaldada kinnitatud säilituspoliitika järgi. Aegunud vahemäluread eemaldatakse käivitumisel ja iga 60 sekundi järel ning otsingukirjed kustutatakse 30 päeva järel.
- Brauser hoiab kuni 50 otsingu teksti ainult avatud lehe protsessimälus, et sama vahelehe tagasi-edasi navigeerimine töötaks; kuni neli jätkuküsimust püsivad sama vastuse Reacti olekus. Neid ei kirjutata püsisalvestusse ning need kaovad lehe uuesti laadimisel või vahelehe sulgemisel; jätkuküsimused kustuvad ka uue juurvastuse avamisel.

OpenCode'i [mudelipõhine privaatsustabel](https://opencode.ai/docs/go/#privacy) märgib Luna sisendi mudelitreeningus mittekasutatavaks, kuid väärkasutuse jälgimise logid võivad säilida kuni 30 päeva. Kõik manageri ja spetsialistide mudelikutsed kasutavad seadet `store: false`; Agents SDK tracing ja tundliku trace-sisu kogumine on välja lülitatud. Need seaded piiravad rakendusepoolset Responses API oleku ja trace'i talletamist, kuid ei lülita välja teenusepakkuja väärkasutuse jälgimise logi. See logi võib sisaldada teenusele saadetud küsimust ja vastust. Teenusepakkuja tingimused võivad muutuda ning need tuleb enne ametlikku kasutuselevõttu uuesti üle kontrollida.

Kõigi anonüümsete klientide mudelitööd jagavad üht libiseva akna päringu- ja tokenieelarvet. Server reserveerib mahu enne teenusepakkuja kõnet; raporteeritud tegelik kasutus asendab reservatsiooni, kuid pärast SDK-le üleandmist teadmata kasutusega katkestus debiteerib konservatiivselt kogu reservatsiooni. Eelarve ammendumisel ei saadeta uut küsimust OpenCode'ile ning kasutaja saab sama tõendipaki deterministliku viidatud vastuse.

## Õiguslik staatus

See dokument kirjeldab praktikaprojekti tehnilist andmevoogu, mitte ametliku teenuse lõplikku privaatsusteadet ega õiguslikku alust. Enne ametlikku kasutuselevõttu peab vastutav töötleja kinnitama õigusliku aluse, säilitustähtajad, kontaktandmed ja teenusepakkuja lepingu.
